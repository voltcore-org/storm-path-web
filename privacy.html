STORM PATH WEB PRIVACY POLICY

Effective 9 September 2026. This page covers the Storm Path website HUD at GitHub Pages. It is separate from the store app binary.

Location

The HUD asks for location only after you tap USE MY LIVE GPS. The first finite GPS fix is the only trigger for National Weather Service and NOAA radar requests. Coordinates stay in the browser except for the public APIs you trigger (NWS, NOAA WMS/RainViewer, OSM Nominatim, OSRM). IP geolocation is view-only and is never treated as GPS. Location is not sold and is not used for advertising.

Voice

Turn-by-turn voice uses the browser Web Speech API on this device. Audio is generated locally. No voice audio is uploaded.

On-device storage

Voice toggle, vehicle marker, dismissed reports, and driver intel pins (3-hour TTL) stay in this browser’s localStorage. There is no Storm Path account on the web HUD.

What we do not collect

  • Name, email, or phone number
  • Payment data
  • Contacts or photos
  • Advertising identifiers

Children

Storm Path is not directed at children under 13.
